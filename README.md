# Hello Command! Shell

This is an Hello Command! Shell that can be used in any terminal environment

*Of course, the source code needs to be compiled by yourself!*

This is a DOS-style shell

**Only Android Termux / Linux can compile and use it.**

**Windows is NOT supported.** Do not try to compile it on Windows (MSVC, MinGW, Cygwin, etc.) — it will NOT work.

This is a Unix-style shell that relies on POSIX APIs (`fork`, `execvp`, `signal`, `ioctl`, etc.). Windows does not provide these natively.
